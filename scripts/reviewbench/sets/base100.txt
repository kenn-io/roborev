# base100: the base set for roborev review-quality evals. It is ReviewBench's
# 25-PR test set, in its own order (so --pr 0-24 still select it), plus 75 PRs
# drawn from the other 194 of the 219-PR full set.
#
# The 75 are biased toward PRs whose golden findings include real high and
# medium severity issues, because those are the issues reviews must find. Each
# PR gets weight 1 + 2*min(high, 3) + 0.5*min(medium, 4), counting only
# true-positive golden findings. The draw is weighted sampling without
# replacement: key = ln(u) / weight, with u taken from
# sha256("base100:" + pr_url), and the 75 largest keys win.
#
# Two PRs are left out of the draw: tallclub/matimo#77 (56,447 changed lines,
# 26 high) and hoangsonww/Claude-Code-Agent-Monitor#58 (15,839 lines, 27 high).
# Either one would hold about a sixth of the set's high findings, so
# high-severity recall would mostly measure those two PRs.
#
# Result: 1,347 true-positive golden findings (106 high, 507 medium). The set
# over-represents PRs with high findings, so its recall is not comparable to
# ReviewBench's published full-set or test-set numbers.
